# Primer entregable del Proyecto 1

## Descripción

Este repositorio contiene los entregables para el primer avance del proyecto.

El avance se divide en dos partes:

* Punto A: Diagrama de conceptos involucrados en el proyecto, generado mediante una herramienta de Inteligencia Artificial, acompañado de la explicación correspondiente.
* Punto B: Análisis y justificación de las estructuras de datos más adecuadas para almacenar la información del proyecto y facilitar de manera eficiente las funcionalidades solicitadas.

## Entregables

### A. Diagrama de conceptos

El documento correspondiente al punto A presenta un diagrama de los conceptos involucrados en el proyecto, junto con la explicación de las relaciones y elementos representados. El diagrama fue generado utilizando Claude, según lo solicitado en las instrucciones del primer avance.

**Documento:** `Entregable1_a_Diagrama_Conceptos.pdf`

### B. Estructuras de datos

El documento relacionado al punto B presenta un análisis de las estructuras de datos finales consideradas más adecuadas para almacenar la información del archivo.

**Documento:** `Entregable1_b_estructura_datos.pdf`
